How to use FouriTre

描いた線を、
回転する円で描き直す。

FouriTre（フーリトレ）は、手描きの線・画像・文字をフーリエ変換し、たくさんの回転する円（エピサイクル）をつなげて元の形を描き直すWebツールです。このページでは操作方法と、その裏側にある数学をまとめて紹介します。

AboutFouriTreとは

どんな閉じた曲線も、「回転速度の違う円をたくさんつなげたもの」の先端の軌跡として表せます。これはフーリエ級数の考え方で、FouriTre はそれを目で見て、手で触って体験できるようにしたビジュアライザです。

キャンバスに一筆書きをすると、その線が離散フーリエ変換（DFT）で周波数成分に分解されます。成分ひとつがひとつの円になり、円を大きい順に連結した先端が、元の線をなぞり直します。円の数を減らすと形が丸くぼやけ、増やすと細部まで再現される様子がリアルタイムで確かめられます。

数学の授業の教材、フーリエ変換の直感的な理解、ちょっと不思議なアニメーション作りなどに使えます。

Quick start3ステップで始める

  1. アプリを開く
    fouritre.vercel.app をブラウザで開きます。最初は「描画」モードです。
  2. キャンバスに一筆書きする
    マウスや指でドラッグして線を描き、離すと変換が始まります。円の連鎖が現れて、あなたの線を描き直します。
  3. 円の数や速さを調整する
    右側のパネル（スマホは右上の設定ボタン）で「円の数」や「描画時間」を変えてみましょう。気に入ったら「書き出し」で画像や動画にできます。
ヒント：描くのが面倒なら「テンプレ」タブのハートや星、または画面下の「自動生成」ボタンを押すだけでも動きを楽しめます。

Input modes4つの入力モード

パネル上部のタブで、何をエピサイクルにするかを選びます。

描画

マウスや指で自由に描きます。「安定化」で手ぶれを抑え、「平滑化」で描き終わった線をなめらかにします。

画像

写真やイラストを読み込み、エッジ（輪郭）を検出して複数の線に変換します。「閾値」で検出の感度、「輪郭数」で使う線の本数を決めます。

テキスト

文字や絵文字の輪郭を描きます。複数行にも対応し、手持ちのフォントファイル（TTF / OTF / WOFF）も読み込めます。

テンプレ

星・ハート・無限大・π・蝶・矩形波・猫・渦巻・DNA・フーリエの肖像を、ワンクリックで呼び出せます。

画像をきれいに変換するコツ

  • 背景が単色で、輪郭のはっきりした画像ほど結果が安定します。
  • 線が多すぎてごちゃつくときは「閾値」を上げるか「輪郭数」を減らします。
  • 設定を変えたら「再検出」で同じ画像を処理し直せます。「単色」でトレースを1色にまとめることもできます。

線の始点と終点が離れていても大丈夫

フーリエ級数は「一周して元に戻る」形を前提とするため、開いた線をそのまま変換すると端と端が直線で結ばれ、そこに波打ち（ギブス現象）が出てしまいます。FouriTre は開いた線を内部で往復の経路として計算し、描画は終点で止めるので、描いたとおりの開いた線として再現されます。

Settingsエピサイクルの設定

円の数（1〜2000）使う周波数成分の数です。少ないほど丸く単純な形に、多いほど元の線に忠実になります。値を変えると描画がやり直されます。
描画時間（0.5〜60秒）線を1周描き終えるまでの秒数です。画面のリフレッシュレート（60Hz / 120Hz）に関係なく同じ速さで動きます。
線幅（0.5〜16）軌跡の線の太さです。
カラー軌跡・円・背景・グリッドの色を自由に変えられます。背景は「グリッド」「ドット」「なし」から選べ、隣のスライダーで間隔を調整します。

Effectsエフェクト

虹色軌跡を虹色のグラデーションで描きます。
残画描き終わった軌跡を画面に残します。オフにすると同じ形を繰り返し描き続けます。
漸出円を1個から少しずつ増やしていき、形がだんだん元の線に近づく様子を見せます。フーリエ級数の収束を体感するのにおすすめです。
鏡像軸に対して線対称な軌跡も同時に描きます。軸の角度と位置を調整でき、軸の表示も切り替えられます。
キラキラペン先から光の粒が飛び散ります。
同期描画複数の輪郭があるとき、すべてが同じ時間で描き終わるようにそろえます。オフでは、細かい輪郭ほど早く描き終わります。

Editing編集操作

  • 移動：オンにして図形の近くをドラッグすると、その図形を動かせます。
  • コピー / ペースト：「コピー」を押してから図形をクリックすると複製元に登録され、「ペースト」で少しずらして貼り付けます。ヘッダーのサムネイルに今コピーしている形が表示されます。
  • 選択削除：オンにしてクリックすると、いちばん近い図形を削除します。「全削除」ですべて消去します。
  • 元に戻す / やり直し：30ステップまで履歴をたどれます。

Export保存と書き出し

ヘッダーの「書き出し」から、ファイル名を付けて保存できます。

  • PNG / JPEG：今のキャンバスを画像として保存します。
  • PNG（透明）：背景を透過した画像です。動画編集やデザインの素材にどうぞ。
  • WebM 動画：最初から描き終わるまでのアニメーションを録画します。
  • JSON プロジェクト：線のデータと設定を保存します。画面下の「読込」で開けば、続きから編集できます。

Mobileスマホ・タブレットで使う

スマホでは、キャンバスを画面いっぱいに使えるよう設定パネルが隠れています。右上の設定ボタンを押すと、下からパネルが出てきます。キャンバスに触れるとパネルは自動で閉じるので、すぐに描き始められます。

指1本でなぞるとそのまま線になります。細かい線を描きたいときは、タブレットとスタイラスペンの組み合わせがおすすめです。

Mathフーリエ変換の仕組み

1. 線を複素数の列にする

描いた線を、長さが等しくなるように N 個の点に打ち直します。各点の座標 (x, y) を複素数 z = x + iy とみなすと、線は複素数の列 z[0], z[1], …, z[N−1] になります。

2. 離散フーリエ変換で周波数に分解する

X[k] = (1/N) · Σn=0..N−1 z[n] · e−i2πkn/N

得られた X[k] のひとつひとつが1個の円に対応します。円の性質は次の3つで決まります。

振幅 |X[k]|円の半径
周波数 k1周するあいだに何回転するか（マイナスは逆回転）
位相 arg X[k]回転を始める角度

3. 円をつなげて描き直す

z(t) = Σk X[k] · eikt　(0 ≤ t < 2π)

半径の大きい順に円の中心を前の円の先端に置いていくと、最後の円の先端が z(t) を描きます。これがエピサイクル（周転円）です。半径の大きい成分ほど形への影響が大きいので、上位の数個だけでも大まかな形が現れ、円を増やすほど細部が加わります。JPEG 画像の圧縮も、同じように「影響の小さい周波数成分を捨てる」という考え方に基づいています。

エピサイクルは、もともと古代ギリシャの天文学で惑星の動きを説明するために考えられたものです。フーリエ級数の視点から見ると、円を十分に重ねればどんな周期的な軌道でも表せることになります。

FAQよくある質問

FouriTreは無料ですか？

はい、無料です。登録やインストールは不要で、ブラウザで開くだけで使えます。

描いた絵や画像はサーバーに送信されますか？

いいえ。フーリエ変換や輪郭抽出はすべてブラウザ内で計算され、描いた線や読み込んだ画像がサーバーに送られることはありません。

円の数を増やすと何が変わりますか？

円の数は使用する周波数成分の数です。少ないと形が丸くぼやけ、増やすほど角や細部まで元の線に近づきます。最大2000個まで設定できます。

スマートフォンでも使えますか？

使えます。指でキャンバスに描けます。設定は右上のボタンで開くパネルから変更できます。

作ったアニメーションを保存できますか？

書き出しメニューから PNG・背景透過PNG・JPEG の画像、WebM 形式の動画、再編集できる JSON プロジェクトファイルとして保存できます。
