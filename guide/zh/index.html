How to use FouriTre

用旋转的圆，

AboutFouriTre 是什么？

任何一条闭合曲线，都可以看成一串以不同速度旋转的圆的末端所描出的轨迹。这就是傅里叶级数的思想，而 FouriTre 是一个让你亲眼看到、亲手体验这一思想的可视化工具。

在画布上一笔画出线条后，它会通过离散傅里叶变换（DFT）被分解成各个频率分量。每个分量对应一个圆，把圆按半径从大到小首尾相连，末端就会重新描出你的线条。减少圆的数量，形状会变圆、变模糊；增加圆的数量，细节会一点点回来，一切都是实时的。

它可以用作数学课的教具，帮助直观理解傅里叶变换，也可以用来制作有趣的动画。

Quick start三步上手

  1. 打开应用
    在浏览器中打开 fouritre.vercel.app，默认是“绘制”模式。
  2. 一笔画出线条
    用鼠标或手指拖动后松开，一串旋转的圆就会出现，并重新画出你的线条。
  3. 调整圆的数量和速度
    在右侧面板（手机上点右上角的设置按钮）中修改“圆的数量”和“绘制时间”。满意后，用“导出”保存为图片或视频。
提示：不想自己画？在“模板”选项卡里选择爱心或星星，或者点击屏幕下方的“随机生成”就能看到效果。

Input modes四种输入模式

用面板顶部的选项卡选择要变成本轮的内容。

绘制

用鼠标或手指自由绘画。“防抖”可以减少手抖，“平滑”会让画好的线条更顺滑。

图片

载入照片或插图，自动检测边缘并转换成多条线。“阈值”决定检测灵敏度，“轮廓数”决定使用多少条线。

文字

画出文字或表情符号的轮廓。支持多行，也可以载入自己的字体文件（TTF / OTF / WOFF）。

模板

一键调出星星、爱心、无穷符号、π、蝴蝶、方波、猫、螺旋、DNA 和傅里叶肖像。

让图片转换效果更好的技巧

  • 背景单一、轮廓清晰的图片效果最稳定。
  • 线条太多太乱时，可以调高“阈值”或减少“轮廓数”。
  • 修改设置后，点击“重新检测”即可重新处理同一张图片。“单色”会把所有轨迹统一成一种颜色。

线条首尾不相连也没关系

傅里叶级数假定图形会回到起点，所以如果直接变换一条不闭合的线，两端会被一条直线连起来，并在那里出现波纹（吉布斯现象）。FouriTre 在内部把不闭合的线当作“去了再回来”的路径来计算，并在终点停止绘制，因此会按你画的样子还原这条开放的线。

Settings本轮设置

圆的数量（1–2000）使用的频率分量个数。越少形状越简单、越圆；越多越接近原来的线条。修改后会重新开始绘制。
绘制时间（0.5–60 秒）画完一整圈所需的秒数。无论屏幕刷新率是 60Hz 还是 120Hz，速度都一样。
线宽（0.5–16）轨迹线条的粗细。
颜色可以自由修改轨迹、圆、背景和网格的颜色。背景可选“网格”“圆点”或“无”，旁边的滑块用来调整间距。

Effects效果

彩虹用彩虹渐变色画出轨迹。
保留轨迹把画完的轨迹留在画面上。关闭后会反复画同一个图形。
渐显从 1 个圆开始逐渐增加，让你看到形状一点点接近原来的线条。很适合体会傅里叶级数的收敛。
镜像同时画出关于某条轴对称的轨迹。可以调整轴的角度和位置，也可以显示或隐藏轴。
闪光笔尖会飞出闪亮的粒子。
同步绘制有多个轮廓时，让它们同时画完。关闭时，越小的轮廓越早画完。

Editing编辑操作

  • 移动：打开后在图形附近拖动，就能移动该图形。
  • 复制 / 粘贴：点击“复制”后再点击图形即可复制，点击“粘贴”会稍微错开位置贴上一份。顶部的缩略图会显示当前复制的图形。
  • 选择删除：打开后点击，会删除离点击位置最近的图形。“全部清除”会删除所有内容。
  • 撤销 / 重做：最多可追溯 30 步。

键盘快捷键

Ctrl + Z撤销
Ctrl + Shift + Z / Ctrl + Y重做
Ctrl + C / Ctrl + V复制 / 粘贴鼠标所在位置的图形

在 Mac 上请用 ⌘ 代替 Ctrl。在文本框中输入时，这些按键会像平常一样复制、粘贴文字。

Export保存与导出

点击顶部的“导出”，可以自定义文件名后保存。

  • PNG / JPEG：把当前画布保存为图片。
  • PNG（透明）：背景透明的图片，适合用作视频剪辑或设计素材。
  • WebM 视频：录制从开始到画完的整个动画。
  • JSON 项目：保存线条数据和设置。之后用屏幕下方的“打开”载入，就能继续编辑。

Mobile在手机和平板上使用

在手机上，为了让画布占满屏幕，设置面板默认是隐藏的。点击右上角的设置按钮，面板会从下方滑出。触碰画布时面板会自动关闭，可以马上开始画。

用一根手指滑动即可画线。想画精细的线条，推荐使用平板和触控笔。

Math傅里叶变换的原理

1. 把线条变成一串复数

先把线条按等长重新取样成 N 个点。把每个点的坐标 (x, y) 看作复数 z = x + iy，线条就变成了复数序列 z[0], z[1], …, z[N−1]。

2. 用离散傅里叶变换分解成频率

X[k] = (1/N) · Σn=0..N−1 z[n] · e−i2πkn/N

得到的每个 X[k] 对应一个圆，由以下三个属性决定：

振幅 |X[k]|圆的半径
频率 k每个周期转几圈（负数表示反向旋转）
相位 arg X[k]开始旋转时的角度

3. 把圆连起来重新画线

z(t) = Σk X[k] · eikt　(0 ≤ t < 2π)

按半径从大到小，把每个圆的圆心放在前一个圆的末端，最后一个圆的末端就会画出 z(t)。这就是本轮（周转圆）。半径越大的分量对形状影响越大，所以只用前几个圆就能看出大致轮廓，圆越多细节越丰富。JPEG 图片压缩也基于同样的思想：舍弃影响较小的频率分量。

本轮最早是古希腊天文学为了解释行星运动而提出的。从傅里叶级数的角度看，只要叠加足够多的圆，就能表示任何周期性的轨迹。

FAQ常见问题

FouriTre 是免费的吗？

是的，完全免费。无需注册或安装，用浏览器打开即可使用。

我画的图或图片会上传到服务器吗？

不会。傅里叶变换和边缘检测都在你的浏览器中完成，画的线条和载入的图片不会被发送到服务器。

增加圆的数量会有什么变化？

圆的数量就是使用的频率分量个数。圆少时形状又圆又模糊；圆越多，棱角和细节越接近原来的线条。最多可以设置 2000 个。

手机上能用吗？

可以。用手指在画布上画即可，设置可以通过右上角的按钮打开面板进行修改。

可以保存做好的动画吗？

在“导出”菜单中，可以保存为 PNG、透明 PNG、JPEG 图片，WebM 视频，以及可以再次编辑的 JSON 项目文件。
